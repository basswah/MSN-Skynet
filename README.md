## 📋 Overview
MSN-Skynet is a highly interactive, responsive web platform tailored for Internet Service Providers (ISPs) focusing on rural connectivity. The application is built to deliver a seamless user experience, featuring dynamic network visualization, coverage mapping, and flexible pricing structures. 

It natively supports both English and Arabic (with full RTL support) and offers a sleek Dark/Light mode toggle to accommodate user preferences.

## ✨ Key Features
* **🗺️ Network & Coverage Visualization:** Interactive components to display service areas and network strength.
* **🌓 Theme Management:** Seamless switching between Light and Dark modes for optimal viewing.
* **🌍 Bilingual Support:** Integrated i18n supporting English and Arabic with dynamic layout adjustments.
* **💳 Pricing Modules:** Clear, responsive pricing cards and comparison sections for various internet plans.
* **🌀 Smooth Scrolling & Animations:** Enhanced user interface with smooth scrolling layouts and engaging component reveals.

## 🛠️ Tech Stack
* **Frontend:** React.js, TypeScript, Tailwind CSS
* **State Management:** Zustand (Custom stores for UI, Theme, and i18n)
* **Tooling:** Vite, ESLint
* **Icons & Assets:** SVG integrations
